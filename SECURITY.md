# Security policy

## Supported versions

Security fixes are applied to the current `main` branch. The extension currently targets GNOME Shell 46 on Wayland.

## Reporting a vulnerability

Please do **not** report a potential vulnerability in a public issue.

Use the repository's **Private vulnerability reporting** form in its Security tab. If that form is unavailable, contact [@incirci](https://github.com/incirci) privately on GitHub with a concise description, impact, and reproduction steps. Please allow reasonable time for a fix before public disclosure.
